# AI-PJ v1.0c 分享合规版 — 使用说明

> ⚠️ **本仓库的修正注（原包没有这段）**：本目录名为 `aipj-1.0`，但 DSH 的预设 id 只接受
> `/^[a-z0-9][a-z0-9-]*$/`（见 `dsh-agent-presets/src/preset.ts:18`），
> 扫描 `~/.dsh/.agent-presets` 时名字不合规的目录被 `discovery.ts` 直接 `continue` **静默跳过**。
> 所以复制到预设目录时**请把目录改名为 `aipj-1`**（本仓库 `install.ps1` 会自动改名）。
> 显示名不受影响，仍是 `preset.yml` 里的「AI-PJ v1.0」。

> 本包 = DeepSeek Harness（DSH）预设三件套：`persona.md`（协议本体）+ `preset.yml`（预设清单）+ `agent.cordis.yml`（官方组件装配，无第三方代码）。
> 基于 AI-PJ v1.0 改造：新增「第零层 · 合规边界」，仅限合规授权场景使用。

## 一、适用场景（第零层授权边界）

本协议只应在以下授权语境中使用：
1. 自有项目调试、自有资产分析
2. 本地/隔离靶场、CTF 平台练习
3. 企业书面授权测试、授权内审
4. 厂商委托的隔离沙箱对抗预研
5. 已立案/已授权的恶意样本分析

**禁止**：一切未授权渗透、非法入侵、灰产开发、针对真实第三方系统的攻击、绕过风控等违法违规行为。

---

## 二、安装方法

### 手动复制
1. 把本文件夹复制到 `%USERPROFILE%\.dsh\.agent-presets\`，并**改名成 `aipj-1`**
   （目录名规则见本文件顶部修正注：只能小写字母/数字/连字符，带小数点会被 DSH 忽略）
2. **完全退出并重启 DeepSeek Harness**
3. 新建会话 → 预设选择器里选 **「AI-PJ v1.0 」**


---

## 三、验证是否生效

1. 重启 DSH，新会话选择本预设；
2. 发送 `hi`（或 `hello` / `你好` / `在吗`，须为完整一条消息）；
3. 收到回复 **`AI-PJ v1.0 已就绪`** = 协议已激活。

## 五、常见问题

**Q：装了没生效？**
A：预设只在启动时扫描——必须完全退出 DSH 进程再重开（不是关窗口）；然后确认新会话的预设选择器里选中的是本预设。

**Q：想确认边界条款在工作？**
A：发一条指向真实第三方域名的未授权请求，正确行为是：一次确认"该目标是你的授权资产或靶场吗？"，或直接给占位符化方法论。

**Q：想自己微调？**
A：直接改 `persona.md`（UTF-8 编码保存）即可；改完重启 DSH。想恢复官方默认 → 删除本预设目录或改名 `.disabled`。

**Q：这个包安全吗？**
A：`agent.cordis.yml` 只引用 DeepSeek Harness 官方内置组件（persona/shell/fs/subagent 等），无任何第三方插件代码、无安装脚本、不修改 DSH 本体文件。
