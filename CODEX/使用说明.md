# AI-PJ v1.1 · Codex 注入版 — 使用说明（双通道跨机版）

> 把 AI-PJ v1.0 注入 OpenAI Codex 桌面端/CLI（~/.codex），
> 使 Codex 会话全时遵循该工作协议。v1.1 支持两种注入通道，适配不同 Windows 电脑。

## 文件清单

| 文件 | 说明 |
|---|---|
| `ai-pj-v1.0-codex.md` | Codex 注入载荷（AI-PJ v1.0 分享合规版 persona + Codex 运行适配段） |
| `install.ps1` | 安装/卸载/检查脚本（自动备份，可 -DryRun 预览，PowerShell 5.1+ 兼容） |
| `双击安装.bat` | **一键安装**（双击即装，无需命令，推荐给所有用户） |
| `双击卸载.bat` | 一键卸载 |
| 本说明 | 使用文档 |

## 两种通道怎么选（v1.1 核心）

| 通道 | 机制 | 适合 | 跨机友好度 |
|---|---|---|---|
| **agents（默认推荐）** | 写 `~/.codex/AGENTS.md`（官方全局指令） | **绝大多数人**：复制一个文件即装；不碰 config.toml；Codex 从未启动过的机器也能装（首次启动即生效）；与用户已有 config 注入并存不覆盖 | ★★★★★ |
| **config** | 写 `config.toml` 的 `model_instructions_file` | 在意"官方自定义系统指令"语义、确认目标机 Codex 已初始化过（有 config.toml） | ★★★☆ |
| both | 两通道同注 | 特殊需求（注意：同内容进 system 两遍 = token 双份） | ★★★ |

**跨机适配已内置**：所有路径用 `%USERPROFILE%` 动态解析（用户名不同也能装）；自动创建 `~/.codex`；已有 AGENTS.md/config 注入会先备份再动（`.bak-aipj-时间戳`）；无 TOML 数组索引风险；卸载只删本包内容（防误删用户自己的 AGENTS.md）。

## 零命令行（推荐，给非技术用户）

1. 整个 `CODEX` 文件夹拷到电脑（U 盘 / 微信 / 网盘均可）；
2. 打开文件夹，**双击 `双击安装.bat`**；
3. 黑色窗口跑完出现 `Done. What to do next` → 按任意键关窗；
4. 完全重启 Codex → 开**新会话** → 输入 `hi` → 回 `AI-PJ v1.0 已就绪` = 成功。

卸载同理：双击 `双击卸载.bat`。（两个 .bat 只调 install.ps1，安全无隐藏动作）

> 若 Windows 弹"已保护你的电脑/来自其他计算机"：点"更多信息 → 仍要运行"（微信/U 盘拷贝一般不会弹）。

## 手动安装（命令行版）

```powershell
cd "此处替换为解压后的 CODEX 目录"

# 1) 先看状态（Codex 检测 / 两通道现状 / 是否有冲突注入）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action check

# 2) 预览（dry-run，不落盘）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install -DryRun

# 3) 正式安装（默认 agents 通道：备份 → 复制载荷到 ~/.codex/AGENTS.md）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install

# 指定 config 通道（目标机 Codex 已初始化过时可选）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install -Channel config
```

## 卸载

```powershell
# agents 通道卸载（只删含本包标记的 AGENTS.md，不会误删用户其他内容）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action uninstall -Channel agents
# config 通道卸载
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action uninstall -Channel config
# 两个都要卸
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action uninstall -Channel both
```

## 生效与验证

1. 完全退出并重启 Codex（桌面端或 CLI 新会话）；
2. 新会话发送 `hi`；
3. 收到 `AI-PJ v1.0 已就绪` = 注入生效（握手标记）。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 装了没生效 | 未重启 Codex / 没开新会话（指令在会话建立时读取）；确认是**新会话**第一条消息发 `hi` |
| Codex 版本过老不支持全局 AGENTS.md | 改用 `-Channel config`（需该机 Codex 至少启动过一次） |
| 提示"config 不存在" | 该机 Codex 从未启动 → 用默认 agents 通道即可 |
| 提示"AGENTS.md 是其他内容" | 用户已有自己的全局指令 → 安装会备份后覆盖；卸载不会删它（安全设计） |
| 卸载后想还原 | 找 `*.bak-aipj-时间戳` 备份改回（AGENTS.md.bak-aipj-* / config.toml.bak-aipj-*） |

## 注意事项

- agents 通道**只写一个文件** `~/.codex/AGENTS.md`（改前自动备份），不碰 config.toml；
- config 通道**只改两处**：`config.toml` 的 `model_instructions_file` 行（改前备份）+ `~/.codex/ai-pj-v1.0-codex.md`；
- 若 config.toml 原先指向其他注入文件，会被替换——备份文件可随时还原；用 agents 通道则不会碰它；
- 注入仅影响 Codex 会话行为，不修改任何工程文件；
- 合规边界见载荷第零层：仅限自有项目/靶场/CTF/书面授权/厂商沙箱；真实第三方未授权对象会做一次确认或转占位符方法论。
