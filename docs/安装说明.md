# 安装说明（详细版 + 排错）

> 简版看 [README 的快速开始](../README.md#快速开始3-步)。这里把所有细节、三种安装方式、每条报错怎么处理都写全。

---

## 0. 为什么破甲包必须"手动"放

客户端的破甲载荷是**启动时**从磁盘固定目录读入的，任何模型都无法在运行中给自己换掉系统提示词。所以：

- ❌ 把 GitHub 链接丢给 AI，让它"自己装一下" → 它没有"写自己预设目录"这个动作，通常只会给你一段读文档式的答复；
- ✅ 你把文件放进指定目录 → 重启客户端 → 客户端启动时读到协议 → 该会话所有轮次都被协议约束。

本仓库把"放哪儿、放什么、怎么验证、怎么回滚"全部固定下来了，照做即可。

---

## 1. 前置条件

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（脚本用 PowerShell；macOS/Linux 请用下面"方式 C 全手动"） |
| PowerShell | 5.1 及以上（Win10/11 自带）。脚本已兼容 5.1 与 7+ |
| DSH 通道 | 已安装 DeepSeek Harness（客户端安装包在 `extra/`，需要时用 `-Action join` 合并） |
| Codex 通道 | 已安装 OpenAI Codex 桌面端或 CLI（未初始化也能装，AGENTS.md 会在首次启动时生效） |
| 权限 | 普通用户即可（只写 `%USERPROFILE%` 下自己的目录，不需要管理员） |

## 2. 方式 A：双击安装（推荐）

1. 解压/克隆出 `dsh-pj-pack` 文件夹（位置随意，路径里**最好不要有奇怪的符号**，中文没关系）；
2. 打开文件夹 → **双击 `双击安装.bat`**；
3. 黑窗口会依次打印：状态检查 → DSH 预设安装结果 → Codex 注入安装结果；
4. 看到 `完成。请务必【完全退出并重启】...` 后按任意键关窗；
5. 完全退出 DSH / Codex 进程，重新打开 → 新建会话 → 按第 5 节验证。

卸载：双击 `双击卸载.bat`。

> 两个 bat 只做一件事：调用同目录的 `install.ps1`。文件是 GBK 编码（cmd 中文才不乱码），内容可用记事本直接查看。

## 3. 方式 B：命令行安装（可预览、可回滚）

```powershell
cd "解压出来的\dsh-pj-pack"

# ① 看状态：载荷在不在、目标现状、是否装过、安装包分卷情况
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action check

# ② 试运行：只打印将要做的事，不写任何文件
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install -DryRun

# ③ 正式安装
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install              # 两个通道都装（默认）
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install -Target dsh   # 只装 DSH 预设
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action install -Target codex # 只装 Codex 注入

# ④ 卸载
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action uninstall
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action uninstall -Target dsh

# ⑤ 需要客户端安装包时：合并 extra\ 分卷并校验
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Action join
```

脚本行为约定：

- 目标已存在**同名预设** → 先改名备份为 `aipj-1.0.bak-<时间戳>`，再写入新内容；
- `%USERPROFILE%\.codex\AGENTS.md` 已存在 → 先备份为 `AGENTS.md.bak-pj-<时间戳>`，再覆盖；
- 卸载时**只删带本包标记（`AP-PROTOCOL`）的内容**；若目标文件/目录是别人的内容，直接跳过并提示，绝不误删；
- `-Action join` 合并后会与 `extra/SHA256.txt` 比对，不一致会明确报错。

## 4. 方式 C：全手动放置（不用脚本，最能看清一切）

### 4.1 DSH 通道

1. 资源管理器地址栏输入（回车）：

   ```
   %USERPROFILE%\.dsh\.agent-presets
   ```

   若 `.dsh` 或 `.agent-presets` 不存在 → 手动新建（注意 `.dsh` 前面有个点）。

2. 把仓库里的 `DSH\aipj-1.0` **整个文件夹**复制进去。

3. 结果应该长这样（4 个文件**直接**躺在预设文件夹里）：

   ```
   C:\Users\<你>\.dsh\.agent-presets\aipj-1.0\
       agent.cordis.yml
       persona.md
       preset.yml
       使用说明.md
   ```

   ❌ 错误示范：

   ```
   ...\.agent-presets\dsh-pj-pack\DSH\aipj-1.0\persona.md      ← 多套了一层，扫描不到
   ...\.agent-presets\aipj-1.0\dsh-pj-pack\persona.md           ← 层级错了
   ```

4. 完全退出 DSH 进程 → 重开 → 新建会话 → 预设选择器选「AI-PJ v1.0」。

### 4.2 Codex 通道

1. 地址栏输入 `%USERPROFILE%\.codex`（没有就新建）；
2. 把 `CODEX\ai-pj-v1.0-codex.md` 复制进去，**改名**为 `AGENTS.md`；
3. 完全重启 Codex → 新会话验证。

> 高级做法（原包自带）：也可以用 `config.toml` 的 `model_instructions_file` 指向载荷文件，
> 详见 `CODEX/使用说明.md`，脚本是 `CODEX/install.ps1`（`-Channel config`）。

## 5. 验证是否生效

| 步骤 | DSH | Codex |
|---|---|---|
| 1 | 完全退出进程（关窗口不算） | 完全退出进程 |
| 2 | 重开 → 新建会话 | 重开 → 新会话 |
| 3 | 预设选择器里选中 **AI-PJ v1.0** | —（全局生效） |
| 4 | 发送一条**只含** `hi` 的消息 | 发送一条**只含** `hi` 的消息 |
| 5 | 应收到 `AI-PJ v1.0 已就绪` | 应收到 `AI-PJ v1.0 已就绪` |

握手触发词：`hi` / `hello` / `你好` / `在吗`，必须**整条消息精确等于**其中之一。
加任何别的内容都不触发标记行（设计如此）。

文件层面的硬核对：

```powershell
Get-FileHash "$env:USERPROFILE\.dsh\.agent-presets\aipj-1.0\persona.md" -Algorithm SHA256
# 期望: 15582C7507BA1268F7613C407855F02E8194FABBF2A4E1F988655AEE27D1EEA4
```

## 6. 排错表

| 现象 | 原因 | 处理 |
|---|---|---|
| 预设选择器里找不到「AI-PJ v1.0」 | 没重启进程 / 目录层级错 / 目录名带空格或点开头被忽略 | 完全退出重开；跑 `-Action check`；确认 `...\aipj-1.0\persona.md` 存在 |
| 选到了预设，但 `hi` 没有标记行 | 这条消息不"只含 hi" / 该会话实际用的是别的预设 | 发送内容改成只有 `hi`；确认会话顶部的预设是 AI-PJ v1.0 |
| 装了但回答还是普通 AI 风格 | 预设未生效（同上）或你改了 `persona.md` 后未重启 | 重启；改文件后必须重启 |
| 提示 `AGENTS.md 是其他内容` | 你已有自己的全局指令 | 安装会先备份再覆盖；卸载不会删别人的内容，从 `.bak-pj-*` 还原 |
| 提示 `config 不存在`（Codex） | 该机 Codex 从未启动过 | 用默认 agents 通道（本仓库脚本默认即是） |
| `install.ps1` 报"禁止运行脚本" | 执行策略限制 | 命令里带 `-ExecutionPolicy Bypass`；或 `Set-ExecutionPolicy -Scope Process Bypass` |
| 双击 bat 一闪而过 | 极少见（路径含特殊字符） | 用方式 B 命令行跑，能看到完整报错 |
| `-Action join` 报哈希不一致 | 分卷下载/拷贝不完整 | 重新获取该分卷，或核对 `extra/SHA256.txt` |
| 想彻底不要了 | — | `-Action uninstall` → 重启客户端 |

## 7. 回滚点清单

安装脚本在覆盖前都会留备份，出问题按时间戳找最近的：

```
%USERPROFILE%\.dsh\.agent-presets\aipj-1.0.bak-<yyyyMMdd-HHmmss>\     ← 旧预设整目录
%USERPROFILE%\.codex\AGENTS.md.bak-pj-<yyyyMMdd-HHmmss>                ← 旧全局指令
```

改回原名即完成还原。
